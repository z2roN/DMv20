# z2roN-DM (z2roN_DM)

지인끼리(최대 15명) 쓰는 1:1 다이렉트 채팅 앱 (Windows / Android, Flutter).

- 사람마다 **내 코드**가 있고, 코드를 주고받아 **서로 수락한 친구만** 목록에 보이며 1:1 대화만 가능합니다. (넓은 화면은 왼쪽 목록 + 오른쪽 대화)
- 대화·파일·이미지는 **WebRTC 직접 연결**(암호화)으로 사용자끼리 바로 오갑니다.
- 접속자 목록과 연결 신호(offer/answer/ICE)만 공용 MQTT 중개 서버(broker.emqx.io 등)를 지나가며, 이것도 상대 코드로 암호화됩니다.
- 앱 암호 + 암호화 저장 + 자동 로그인(암호 기억하기).
- 빌드: GitHub에 올리고 Actions "z2roN_DM 빌드" 실행 (자세한 설명은 .github/workflows/build.yml 맨 위).

한계: 직접 연결이 막히는 네트워크(일부 회사망/이동통신망)에서는 연결되지 않습니다. 앱이 꺼져 있으면 받을 수 없습니다(서버가 없어 대신 보관하지 않음).
